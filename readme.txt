ページ内の画像を指定して、その画像のExif情報を表示するブロックを追加します。

== Description ==

投稿・固定ページに配置した画像の撮影情報（Exif）を表示するブロックです。

**主な機能:**

* 直前の画像ブロック（ギャラリーの場合は最後の画像）を自動で対象にする。設定パネルでページ内の任意の画像に切り替えることもできる
* 表示項目: カメラ、レンズ、焦点距離、35mm換算焦点距離、F値、シャッター速度、ISO感度、露出補正、撮影モード、フラッシュ、ホワイトバランス、撮影日時（項目ごとに表示/非表示を切り替え可能）
* レイアウト: テーブル / インライン / アイコン付きリスト
* ラベルの表示/非表示、インライン表示の区切り文字を設定可能
* 色・タイポグラフィ・余白・枠線はブロックの標準機能でカスタマイズ可能

**プライバシー:**

* GPS（位置情報）は取得・保存・表示のいずれも行いません。
* 非公開・下書き・パスワード保護された投稿に属する画像の撮影情報は、閲覧権限のある人にだけ表示されます。

**注意事項:**

* 画像が未選択の場合や、画像にExif情報がない場合、フロントエンドでは何も表示されません。
* 画像編集ソフトやSNS向けの書き出しでExifが削除された画像では、情報を表示できません。
* PHPのExif拡張が無効な環境では、WordPressがアップロード時に保存した情報（カメラ・F値・シャッター速度・ISO・焦点距離・撮影日時）のみ表示します。

== Installation ==

1. `/wp-content/plugins/next-exif-display-block` ディレクトリにプラグインファイルをアップロード
2. WordPressの「プラグイン」画面でプラグインを有効化
3. 投稿またはページの編集画面で、画像ブロックの直後に「Exif情報」ブロックを追加
